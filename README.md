 Amazon Clone

A simple Amazon homepage clone built using **HTML** and **CSS**.
This project is created for frontend practice and to improve webpage layout and styling skills.

-Features

* Amazon-like homepage UI
* Responsive navigation bar
* Search bar design
* Product sections
* Footer section
* Clean layout using CSS

-Technologies Used

* HTML5
* CSS3

- Project Structure

amazon-clone

├── index.html

└── README.md

Through this project, I learned:

* HTML page structuring
